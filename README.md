# Engenharia Prefeitura - atualizações

Arquivos da atualização automática do aplicativo **Engenharia Prefeitura**
(Prefeitura Municipal de Lambari - Setor de Engenharia).

- `publicar/SETUP ENGENHARIA PREFEITURA.exe`: instalador da versão atual.
- `publicar/versao.json`: número da versão, SHA-256, tamanho e novidades. O app instalado lê este arquivo.

O app só instala um Setup cujo tamanho e SHA-256 conferem com o `versao.json`.
Este repositório não tem código-fonte nem dados.
